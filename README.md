# Project Name: FitLog


## Short Description
FitLog is a responsive workout library website. Users can explore different workouts, 
view workout details, save workouts, and create a plan for today's exercises.



## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- LocalStorage


## Features

- Browse different workout exercises.
- View detailed information about each workout.
- Add workouts to Today's Plan.
- Save workouts for later.
- Sort workouts by Duration, Calories, and Rating.
- Remove workouts from Today's Plan or Saved list.
- Mark workouts as Done.
- Responsive design for mobile, tablet, and desktop.
